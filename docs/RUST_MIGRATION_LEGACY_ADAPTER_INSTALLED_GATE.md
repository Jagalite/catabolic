  `453fca983222c6665a48775eef67c489c96b527e`

The shared strict-artifact gate checks the complete installed wheel, packaged
helper bytes, helper manifests, build manifest, source digest, and matching
external build helpers. Actual fixture native launches use the installed packaged

The frozen bootstrap preserves reviewed fixture code/arguments and adds explicit
interpreter, source/import, and bootstrap identity checks. Oracle parents use
`-I -B`; the existing pinned `PYTHONPATH` contract is verified and retained for
nested frozen HTTP/identity children. `PYTHONSAFEPATH=1` and
`PYTHONNOUSERSITE=1` are set and verified on every oracle parent so unchanged
frozen `python -m` children cannot prepend cwd or user-site packages. A real
non-isolated child-import probe records interpreter flags and exact frozen

Fresh disposable bytecode-cache prefixes
prevent stale source bytecode from standing in for recorded bytes. The installed

trusted immutable source and fixtures; they are not arbitrary Python sandboxing.
